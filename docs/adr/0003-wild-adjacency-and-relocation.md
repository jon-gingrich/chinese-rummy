# Wild adjacency and relocation

Jokers and twos are both wild. No two wilds (of any mix) may sit in adjacent slots. This applies to sets and runs alike — so three jokers in a set of four is never legal — and it applies when a wild is first played and when a wild is relocated.

When a player lay-offs by replacing a wild with a natural card, the displaced wild must move to a set or run on the same player's board — including extending the same meld when that keeps wilds non-adjacent. The lay-off player chooses the destination among legal options. If the current meld has no legal non-adjacent slot for the freed wild, it must relocate to another meld on that board.
