# Wild adjacency and relocation exception

Jokers and twos are both wild. When first played in a meld, no two wilds (of any mix) may sit in adjacent slots. This applies to sets and runs alike — so three jokers in a set of four is never legal.

When a player lay-offs by replacing a wild with a natural card, the displaced wild must move to another set or run on the same player's board. The lay-off player chooses the destination. During that relocation only, adjacency rules are waived — a future reader might assume one global rule, but the exception is deliberate table practice.
