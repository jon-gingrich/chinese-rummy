# Exact contract meld sizes on opening

Each round's contract requires melds of precise sizes — for example, round 1 is two sets of exactly three cards, not two sets of at least three. A set of four does not satisfy a "set of 3" slot in the contract.

Many rummy variants treat contracts as minimum sizes, which would allow larger melds on the opening turn. This house rule is stricter and changes which hands can open on a given round. Encoding the wrong interpretation would silently change the game.
