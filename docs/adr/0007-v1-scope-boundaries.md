# v1 scope boundaries

Version one ships the full ten-round contract game online for two to five players with room codes, light accounts, and save/resume. It explicitly excludes bots, mid-game join, spectators, in-app chat, leaderboards, native apps, a house-rule editor, full async play, and polished animations beyond basic card moves.

These cuts keep the first release focused on a faithful rules engine and a playable table. Async play and bots were deferred in favour of live multiplayer with persistent state — a different architecture than turn-by-email.
